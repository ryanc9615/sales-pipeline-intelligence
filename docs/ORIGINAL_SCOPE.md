# Sales Pipeline Intelligence Tool — Original Scope

**Source:** Ryan's project brief, 31 October 2026. This section preserves the requested outcome. The planning assumptions below are separate from the brief.

> Beginner · Revenue / GTM · 3 weeks
>
> Build: A simple application where a sales manager uploads CRM data and immediately sees pipeline health, conversion rates, stalled deals and revenue forecasts.
>
> Technical skills: Python, data structures, pandas, Git, API fundamentals, Streamlit or a simple web UI, testing and deployment.
>
> New commercial skills: Sales pipelines, win rates, weighted forecasts, pipeline coverage and sales-cycle analysis.
>
> Completion evidence: A deployed dashboard, sample dataset, validated revenue calculations and an explanation of three actionable sales insights.
>
> ChatGPT will act as my tutor, CTO and senior architect, engineer etc to coach me through this project.

## Agreed planning baseline

- Build this personally as a technical apprenticeship and a commercial portfolio project.
- Reuse the **documentation and tutoring structure** of Scenario Financial Engine: engineering specification, phased roadmap, tutor protocol, phase prompts and a factual project-state handoff.
- Target three weeks and approximately 40 focused hours, with a planning range of 36–48 hours. The estimate is a starting assumption, not a guarantee.
- Use Python, pandas and Streamlit. A single CSV snapshot, one fictional business and GBP only keep V1 manageable.
- The application forecasts **deal bookings / contract value**, using explicit stage probabilities. It does not calculate accounting revenue recognition, MRR, ARR or cash collections. Explain this distinction in the dashboard and portfolio.
- Conversion measures must be supported by the uploaded data. A single current-state snapshot supports closed-deal win rates and observed creation-cohort conversion; it cannot establish stage-to-stage conversion histories.
- Preparing this project pack does not implement or deploy the application. Phase 00 begins the learner's build.
